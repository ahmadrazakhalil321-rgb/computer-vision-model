# YOLO Vision AI — Object Detection for Images & Videos

An interactive Streamlit web application powered by **Ultralytics YOLO** that accepts images or videos as inputs and returns them annotated with labeled bounding boxes around detected objects.

## Features
- **Dual Media Support**: Upload photos (JPG/PNG) or videos (MP4/MOV/AVI).
- **YOLO Bounding Boxes**: Automatically detects objects and renders bounding labels directly onto the media.
- **Adjustable Threshold**: Customize detection confidence via the sidebar.
