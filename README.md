# Vision AI — Picture & Video Inspector

An interactive web application built with **Streamlit** and **Google Gemini Flash** that performs multimodal computer vision analysis on both **images** and **videos**.

## Features
- **Dual Media Support**: Upload photos (JPG/PNG) or videos (MP4/MOV/AVI).
- **Object & Scene Detection**: Catalog objects, people, and architectural elements.
- **Video Event Tracking**: Break down sequential actions and timestamps.
- **Custom Querying**: Ask tailored questions about any visual asset.
